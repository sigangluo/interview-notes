# 面经与复盘

真实面试的记录，按岗位放在 `技术/` 或 `产品/` 下，一场面试一个文件，文件名为 `公司-岗位-轮次-YYYY-MM-DD.md`，例如 `字节-AI应用开发-一面-2026-10-15.md`。

每个文件包含：

1. **基本信息**：公司、岗位、轮次、时长、形式。
2. **题目与回答**：按顺序记录问题和自己当时的回答要点。
3. **复盘**：答得不好的地方、正确答案或更好的讲法，并链接到对应的知识文件（比如 `../../技术/全栈开发/后端/Java并发.md`），把补充内容写回那里。

公开之前注意：

- 不写面试官姓名等可以识别个人的信息。
- 公司明确要求保密的题目不写。
- 不想公开的记录用 `*.private.md` 命名，不会被提交。
